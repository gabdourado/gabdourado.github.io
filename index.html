1. Python

Python é uma linguagem de programação criada em 1991 pelo programador holandês Guido van Rossum. Sua sintaxe simples e legível a tornou uma das linguagens mais populares do mundo, sendo amplamente adotada tanto por iniciantes quanto por grandes empresas de tecnologia. Um dos principais motivos do seu sucesso é a versatilidade: o Python é extremamente utilizado na área de Ciência de Dados, onde ajuda a analisar e visualizar grandes volumes de informação, e também é uma das linguagens preferidas para o desenvolvimento de sistemas de Inteligência Artificial, sendo a base de frameworks famosos como TensorFlow e PyTorch.
