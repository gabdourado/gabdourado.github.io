# 10 Linguagens que Você Precisa Conhecer

**Integrantes:** Gabriel Dourado

## Descrição do Projeto

Site desenvolvido para a disciplina de Desenvolvimento Web, apresentando 10 linguagens de programação populares. Para cada linguagem, o site traz o ano de criação, o(s) criador(es) e as principais áreas de aplicação. O projeto também conta com uma página de formulário para avaliação do site e uma página sobre os desenvolvedores (alguns são fictícios).

**Link do site publicado:** [gabdourado.github.io]
